# 宣传文案

## 一句话

Word 题库拖进去，转身变成能刷的题。离线，不登录。

## 仓库简介（GitHub / Gitee 描述栏）

Word 题库自动分题 + 离线刷题：解析台、错题本、限时模拟考，纯前端单文件，附 Android 壳。

## 群里发

做了个小工具，叫茶茶刷题。

起因是手里那份竞赛题库，685 行 Word，选项挤一行、答案标红、还夹着表格，市面上的刷题 App 都不认。我写了个解析器，180 道题一次全分出来，待确认 0 道，一道没手改。

现在能随机刷、只刷错题、限时模拟考，错题本和报告都有。手机装 APK，电脑开一个 HTML 文件就能用，数据全在本地，不登录也不联网。

仓库在 GitHub：https://github.com/17855880027WuYutao/cha-cha-shuati

## 朋友圈
