# 刷题解析台 v0.4

Word 题库 → 结构化题目 → 刷题。手机浏览器直接用，离线也行。

## 打开方式

**方式一：单文件版（推荐手机上用，不用服务器）**

`dist/刷题解析台.html` 拷到手机上（或电脑任意位置），文件管理器里点开、选浏览器就能用。
示例题库、解析器、样式全在这一个文件里，断网可用；右上角「导入 Word」可以选自己的 .docx。

**方式二：本地服务（电脑上改代码方便）**

```sh
cd quiz
python3 -m http.server 8100
```

浏览器打开 <http://127.0.0.1:8100/>（要在系统浏览器里，别用聊天 App 的内置浏览器）

- 示例题库默认用 `samples/dirty.docx`（自造的脏格式样例），加 `?sample=dirty` 也加载它
- 点标题 3 下导出 JSON（电脑上 Ctrl/Cmd+E）
- 单文件版改完要重新打包：`node test/build-single.js`

## 四个面板

顶部只有一行标题（题库/导入）+ 一行页签（题目/原文/刷题/错题/报告），其余全留给内容；刷题会话里连这些也隐藏。

| 面板 | 干什么 |
| --- | --- |
| 题目 | 解析结果：题型、题干、选项、答案、置信度、待确认标记 |
| 原文 | Word 原始行流，标黄 = 题目开头，红字 = 答案 |
| 刷题 | 随机/顺序/只刷错题/**限时模拟考**，打乱选项，本机续刷 |
| 错题 | 错题列表（按错的次数排）、展开看选项和解析、一键刷全部、清空 |
| 报告 | 我的标记（收藏/标记可查可删）、刷题记录、题型分布、分节、待确认、重复题、未归类 |

## App 版

`quiz-app/build/茶茶刷题.apk`（约 286KB）：同一个页面包成 Android App，装完桌面有图标「茶茶刷题」。
源码在 `/root/workspace/quiz-app/`，改完页面跑 `node test/build-single.js` 再 `bash quiz-app/build.sh` 重打包。

## 多题库

- 右上角「题库」：列出所有存过的题库，显示题数/错题数，点一下切换，也可以删
- 导入新的 .docx 会自动进库并切过去；进度和错题按题库分开记
- 题库存在本机 localStorage，存不下时会提示先删旧的

## 模拟考

- 刷题设置里选「模拟考」，挑题量（20/50/100/全部/自定义）和时长（15/30/60/90/120 分钟，或自定义 1–300）
- 考试中不判对错，可以上一题/下一题来回改，顶部倒计时，最后 1 分钟变红
- 交卷（或到点自动交卷）出分：正确率、对错数、未答数、逐题答案回顾
- 没答的题按错算

## 题量 / 题型筛选

- 题量：20 / 50 / 100 / 全部 / 自定义（1–1000）
- 题型：按当前题库里真实存在的题型出按钮（单选/多选/判断/填空/简答），可以多选；题库里没有的题型不显示
- 筛选对随机/顺序/只刷错题/模拟考都生效

## 报告里的收藏 / 标记 / 记录

- 「我的标记」三个入口：**收藏 N · 标记 M · 刷题记录 K**
- 收藏/标记列表：题干 + 答案，右侧「取消收藏 / 取消标记」直接删；按题库分开存，换题库不丢
- 刷题记录：每刷完一组（练习或模拟考）记一条 —— 时间、模式、题量、对几错几、跳过几题、用时、正确率；本机每库保留最近 60 条，可清空
- 中途退出的那一组不记

## 刷题页（方案 A）

- 题目卡片在剩余空间里**垂直居中**，短题不再吊在上半屏；题干很高时整块可滚，不会顶掉
- 底部固定一条：**答题卡**（点开是题号网格，对/错/未答/当前四色，点题号跳题；带「跳」标记的是跳过的）+ **收藏**（按下去变黄）+ **标记**（按下去变浅绿）+ **跳过**
- 跳过的题不进对错统计，答题卡里有「跳」标记，结束页可以「重刷跳过的 N 题」

## 刷题手感

- 进入刷题后自动全屏：顶栏、统计、页签都让出来，题目从最上面开始
- 一屏一题，单选/判断点完立刻判，多选「提交」判，填空回车判；提交按钮居中
- 判完「提交答案」原地变「下一题」，不用去页面底部找按钮
- 按钮有按压缩放动效；点选项/提交/切页签会短振动（安卓浏览器支持 `navigator.vibrate`，微信内置浏览器可能没有）
- 题与题之间是滑动+淡入过渡（新题从右侧进，旧题向左淡出）
- 答完显示对错 + 正确答案 + 解析，底部固定「下一题」
- 打乱选项时答案字母跟着重映射（多选也一样）
- 错题自动进错题本，可按错题次数重刷
- 进度、错题本存在本机 localStorage，刷新/关掉再打开能接着刷
- 填空宽松判：忽略空格、全半角、标点；多空用 `；` 隔开按顺序比对

## 解析能力（实测）

| 题库 | 结果 |
| --- | --- |
| 校赛复赛题库（外部导入，不随仓库分发） | 180 题（70 单选 / 70 多选 / 40 填空），0 待确认，0 未归类 |
| 课程复习题库（外部导入，不随仓库分发） | 438 题（275 单选 / 93 多选 / 53 填空 / 16 判断 / 1 简答），0 未归类；检出 1 组重复题（93、94 题干相同但答案 A/D 冲突） |
| 脏格式样例（自造） | 14 题全对：合并选项、圈号选项、制表符、图片、题干表格、隐藏字答案、文末答案表 |

能认的东西：大节标题、题号（`1.` / `1、` / `第1题` / Word 自动编号）、选项（`A.` / `A、` / `①` / 挤在一段 / tab 分隔）、答案（`答案：` / 红字 / 白字 / 隐藏字 / 文末答案清单 / 题号|答案 表格）、题干里的图片和表格、表格版题库。

## 已知边界

- 只支持 `.docx`；老 `.doc` 要先另存为 docx（有的「.doc」其实是 HTML，也能另存）
- 题干整页是截图的不 OCR
- 答案在另一份文件里不行
- 填空题多空按顺序比对（`安全性高；稳定性好`），顺序反了算错
- 错题本按题库区分，换题库不会串
- 旧版本存的题库没保存原文行，切过去「原文」会提示重新导入一次；新导入的题库都带原文
- 两栏横排等怪排版可能漏，看报告「未归类行」
- 页面高度用 JS 量 `innerHeight` 写进 `--app-h`，兼容不认 `100dvh` 的老 WebView
- 原文页首屏只画 200 行，剩下的点「显示更多」追加；切页签不再重绘刷题面板
